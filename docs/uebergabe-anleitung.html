Teil A · allein · etwa 1 Stunde

Was du vorbereitest

Alles in Teil A kannst du ohne Valentin machen, in beliebiger Reihenfolge. Am Ende schickst du ihm die vier Angaben aus dem Kasten auf Seite 4. Nimm überall dieselbe E-Mail-Adresse — am besten info@hahntime.com —, dann passen die Konten später zusammen.

Hannes5 Minuten

3

Hannes3 Minuten

Damit Claude in deinem Shop Uhren anlegen darf. In claude.ai unten links auf deinen Namen → Einstellungen → Connectors (auch „Integrationen") → Shopify → Verbinden. Es öffnet sich die Shopify-Anmeldung: mit deinem Shop-Login (info@hahntime.com) anmelden, den Shop tami1g-0j wählen, den Zugriff bestätigen.

An Valentin schicken: ein Wort — „Shopify verbunden".
4

Eigenes Vercel-Team anlegen

Hannes10 Minuten

Vercel liefert die Website aus. Sie liegt im Moment noch in Valentins Konto — zusammen mit seinen anderen Kundenprojekten. Deshalb bekommt sie ein eigenes Team unter deinem Namen, in das wir sie in Teil B umziehen. vercel.com → Sign up → mit info@hahntime.com (oder „Continue with GitHub", wenn dein GitHub-Konto diese Adresse hat). Dann oben links auf deinen Namen → Create Team → Name zum Beispiel „Hahn und Vo OHG" (ein „&" nimmt Vercel nicht an) → Tarif Pro → deine Karte hinterlegen.

Warum Pro und nicht kostenlos: Vercel erlaubt den Gratis-Tarif nur für private, nicht-kommerzielle Seiten, und man kann niemanden ins Team holen. Wird ein Kontingent überschritten, schaltet Vercel die Seite im Gratis-Tarif ab, statt es zu berechnen. Ein laufender Uhrenshop gehört auf Pro (20 $/Monat). Konto, Rechnung und Vertrag laufen damit auf dich — nicht mehr auf Valentin.
Fertig, wenn: dein Team unter Settings → Billing „Pro" zeigt. Es ist noch leer — die Website kommt in Teil B.
An Valentin schicken: „Vercel-Team steht" und den Namen des Teams.

Hannes2 Minuten

Resend verschickt die Mails aus „Suchauftrag" und „Ankauf" an info@hahntime.com. Das Konto gehört dir schon — einmal einloggen: resend.com → Sign in. Unter API Keys liegt der Schlüssel „hahn-vo-website", den Valentin im Website-Hosting hinterlegt hat. Nichts löschen — den Schlüssel erneuern wir zusammen in Teil B, damit kein Schlüssel mehr in Umlauf ist, den Valentin kennt.

Fertig, wenn: du eingeloggt bist und den Schlüssel unter API Keys siehst.
An Valentin schicken: „Resend-Login klappt".
6

Claude Code als Mac-App installieren

Hannes5 Minuten

Du brauchst kein Terminal. Claude Code gibt es als Mac-App: claude.com/claude-code → Download für Mac → installieren → mit deinem Claude-Konto anmelden. Alles Weitere, was der Mac im Hintergrund braucht (git, Python, den Browser fürs Inseratlesen), installiert Claude selbst, sobald wir in Teil B das Projekt öffnen — du bestätigst nur Apple-Dialoge und gibst einmal dein Mac-Passwort ein.

Wer lieber im Terminal arbeitet: npm install -g @anthropic-ai/claude-code — dann ist der Start claude im Projektordner. Ergebnis ist dasselbe.

Fertig, wenn: die App startet und dein Name oben steht. Außerdem: macOS ist aktuell, du kennst dein Mac-Passwort, und du kannst den Bildschirm teilen (FaceTime, Zoom, Teams — egal was).

Was wir in Teil B nicht mehr tun müssen

Das steckt schon im Projekt und wandert mit dem Repo mit: die fünf Skills (Uhr anlegen, Status setzen, löschen, Bilder ändern, Website ändern), die Werkzeuge dahinter — inklusive der Uhren über 8.500 €, die „per Überweisung" laufen —, die Regeln (z. B. Besteuerung, Bildreihenfolge, interne Codes), und eine Liste aller Fehler aus dem Aufbau mit ihrer Lösung. Nichts davon hängt an Valentins Konto.

Kurz gesagt: Teil A sind Konten. Teil B ist Verbinden und Üben. Danach machst du im Alltag nur noch eins: Claude sagen, was passieren soll.

Hannes tipptValentin schaut zu60–90 Minuten
